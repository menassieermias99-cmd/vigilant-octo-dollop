#vigilant-octo-dollop

A modern full-stack web application built with Next.js 16 (App Router & Turbopack), Prisma 7 ORM, and Neon serverless PostgreSQL.

---

# Tech Stack

-**Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack) -**Language:** [TypeScript](https://www.typescript.org/) -**Database:** [Neon PostgreSQL](https://neon.tech/) (Serverless) -**ORM:** [Prisma 7](https://prisma.io) with '@primsa/adapter-neon' -**Deployment:**[Vercel](https://www.vercel.com)

🌐 **Live Demo:** [https://vigilant-octo-dollop-alpha.vercel.app/](https://vigilant-octo-dollop-alpha.vercel.app/)
